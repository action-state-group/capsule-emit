# Number canonicalization vectors

Shared Python/Go vectors for turning decoded JSON numbers into digest-safe
values: `capsule_emit.numbers.canonicalize_for_digest` (Python) and
`emit.CanonicalizeForDigest` (Go). Each case is JSON text; both languages
decode it, run the helper, and compute the AAC JSON-DIGEST. A case has either
the expected `digest` or `"error": true` (no digest representation: NaN,
infinities, binary64 overflow, integers outside ±(2^53−1)).

`vectors.json` is generated by the Python reference (`generate.py`); the Go
test must reproduce every digest byte for byte.
